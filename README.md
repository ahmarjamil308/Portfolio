# Ahmar Jamil Portfolio

A responsive React + Vite portfolio with CSS 3D-inspired hero visuals, Framer Motion entrance/scroll animations, project cards, skills, experience, services, and a mailto contact form.

## Run locally

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
npm run preview
```

## Personalize

- Update links and contact details in `src/config/profile.js`.
- Add your photo at `public/images/ahmar-jamil.jpg` (create the folders if needed).
- Update project demo/repository URLs in `src/components/Projects.jsx`.
- The contact form opens the visitor's email app; it does not send/store messages through a backend.

The portfolio intentionally does not display a ByteShift job title or role.
